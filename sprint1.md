# Sprint 1 - CRUD Productos
Sistema: ProductHub
Metodología: SCRUM
Sprint: 1
Duración: 1 semana

---

## Objetivo del Sprint
Convertir el listado estático de productos en un listado dinámico utilizando JavaScript puro, implementando la funcionalidad básica de Create y Read.

---

## Qué se hizo

- Se creó un arreglo dinámico de productos.
- Se implementó validación básica de campos.
- Se desarrolló la función para agregar productos al arreglo.
- Se renderizan los productos dinámicamente en el DOM.
- Se integró diseño con Bootstrap.
- Se agregó buscador de productos.
- Se implementó flujo Git con ramas feature y Pull Requests hacia develop.

## Problemas encontrados

- Error de carga de archivos Js por rutas incorrectas.
- Conflictos menores al integrar ramas.
- Errores de consola generados por extensiones del navegador.
- Ajustes en el renderizado de imágenes para que se mostraran completas.
- El index no cargaba el diseño por escribir mal el nombre del style.

---

## Resultado final

El sistema permite:
- Visualizar productos dinámicamente.
- Agregar nuevos productos.
- Validar campos antes de guardar.
- Buscar productos por nombre o categoría.
- Trabajar bajo metodología SCRUM con flujo Git estructurado.

Sprint completado exitosamente.
